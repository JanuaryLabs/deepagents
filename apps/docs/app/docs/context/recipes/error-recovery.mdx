---
title: Error recovery with guardrails
description: Intercept API errors and trigger self-correction retries using guardrails
---

This recipe configures an agent to recover when a provider rejects a call to
an unregistered tool. The guardrail returns corrective feedback, and the
agent can retry with the updated context. Whether a model attempts the invalid
call depends on the provider and model.

## Scenario

1. System prompt tells the model to use a `tell_joke` tool
2. The sandbox provides `bash`, `readFile`, and `writeFile`, but no `tell_joke` tool
3. If the model calls `tell_joke`, the provider may reject it with a tool-not-found error
4. `errorRecoveryGuardrail` matches the error message and provides corrective feedback
5. The agent retries and can respond with plain text or use a registered tool

## Setup

Create a context engine with a system prompt that references a non-existent tool:

```typescript
import { groq } from '@ai-sdk/groq';
import { InMemoryFs } from 'just-bash';
import { randomUUID } from 'node:crypto';

import {
  ContextEngine,
  type ContextFragment,
  InMemoryContextStore,
  agent,
  createBashTool,
  createVirtualSandbox,
  errorRecoveryGuardrail,
  role,
  user,
} from '@deepagents/context';

function engine(...fragments: ContextFragment[]) {
  const context = new ContextEngine({
    userId: 'demo-user',
    store: new InMemoryContextStore(),
    chatId: randomUUID(),
  });
  context.set(...fragments);
  return context;
}

const context = engine(
  role('You are a helpful assistant. Use the tell_joke tool to tell a joke.'),
  user('Hello! Tell me a joke please.'),
);
```

## Add a custom safety guardrail

You can stack multiple guardrails. Here's a content safety filter alongside the built-in error recovery:

```typescript
import { type Guardrail, fail, pass } from '@deepagents/context';

const safetyGuardrail: Guardrail = {
  id: 'safety',
  name: 'Safety Filter',
  handle: (part) => {
    if (part.type === 'text-delta') {
      if (part.delta.toLowerCase().includes('hack')) {
        return fail(
          'I should not provide hacking instructions. Let me suggest ethical alternatives instead.',
        );
      }
    }
    return pass(part);
  },
};
```

## Create the agent

Create a virtual sandbox and pass it to the agent with both guardrails.
The sandbox supplies the required tools; `tell_joke` remains unregistered:

```typescript
const sandbox = await createBashTool({
  sandbox: await createVirtualSandbox({ fs: new InMemoryFs() }),
});

const jokeAgent = agent({
  name: 'joke_agent',
  sandbox,
  context,
  model: groq('gpt-oss-20b'),
  guardrails: [errorRecoveryGuardrail, safetyGuardrail],
  maxGuardrailRetries: 3,
});
```

## Stream and consume

Consume `toUIMessageStream()` to apply the guardrails. Supply an error
formatter that preserves the provider's message so `errorRecoveryGuardrail`
can recognize it:

```typescript
try {
  const stream = await jokeAgent.stream();
  const response = stream.toUIMessageStream({
    onError: (error) =>
      error instanceof Error ? error.message : String(error),
  });

  for await (const part of response) {
    if (part.type === 'text-delta') process.stdout.write(part.delta);
  }
} finally {
  await sandbox.sandbox.dispose();
}
```

## What happens under the hood

When the provider reports the unregistered tool, a successful recovery follows
this sequence:

```
1. Model receives system prompt mentioning "tell_joke" tool
2. Model attempts to call tell_joke → API error (tool not in request.tools)
3. errorRecoveryGuardrail intercepts the error part
4. Guardrail returns fail() with feedback: "The tool tell_joke is not available..."
5. Accumulated text + feedback injected as self-correction message
6. Model retries — this time responds with plain text (no tool call)
7. safetyGuardrail checks each text-delta — all pass
8. Response reaches the user
```

## Key takeaways

- **`errorRecoveryGuardrail`** handles common API errors (missing tools, malformed JSON, schema mismatches) automatically
- **Guardrails compose** — stack multiple guardrails and they run sequentially on each stream part
- **`maxGuardrailRetries: 3`** allows the initial attempt and up to two self-correction retries
- **Guardrails only apply via `stream.toUIMessageStream()`** — reading `stream.result.stream` or `stream.result.textStream` bypasses them
