# Toolbox

`@deepagents/toolbox` exports a few tools that an agent registers directly:

- `hackernewsTools`: tools that search Hacker News through its Algolia API
  (stories, comments, Ask HN, Show HN, jobs, polls, users and domains).
- `scratchpad_tool`: a reflection tool that the model calls to plan its next
  step after a search.
- `repoTree(directory)`: prints the files a Git repository tracks, as a tree.

```typescript
import { hackernewsTools, scratchpad_tool } from '@deepagents/toolbox';

const tools = { ...hackernewsTools, scratchpad_tool };
```

To run commands for an agent, give it a sandbox instead:
`createBashTool` from `@deepagents/context` runs bash over a virtual, Docker,
Apple container or microsandbox session. For web search, use a provider's
search tool or the AI Gateway's search tools.
