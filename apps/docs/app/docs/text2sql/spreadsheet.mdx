---
title: Spreadsheet
description: Query Excel, CSV, and TSV files with natural language using Text2SQL
---

The `Spreadsheet` adapter loads Excel (`.xlsx`/`.xls`), CSV, and TSV files
into SQLite. Excel sheets become separate tables; CSV and TSV files each
become one table. The database stays in memory unless you set `database`
to a file path.

## Installation

The adapter requires the optional peer dependency `xlsx` for every supported
format, including CSV and TSV. Other Text2SQL adapters do not need it.

Install SheetJS `xlsx` 0.20.3 from its CDN. npm 12 blocks this URL by default.
Add the following to your project's `.npmrc` to allow URL dependencies
declared directly in your project's `package.json`:

```ini
allow-remote=root
```

Then install the package and `xlsx`:

```bash
npm install @deepagents/text2sql https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz
```

## Basic setup

```typescript
import { Text2Sql, toSql } from '@deepagents/text2sql';
import { Spreadsheet, info, tables } from '@deepagents/text2sql/spreadsheet';

// Reuse model from Getting Started.
const adapter = new Spreadsheet({
  file: './sales-data.xlsx',
  grounding: [tables(), info()],
});

const text2sql = new Text2Sql({
  adapters: { main: adapter },
});

const fragments = await text2sql.index({ names: ['main'] });
const { sql } = await toSql({
  input: 'What are the top 5 products by revenue?',
  adapter,
  fragments,
  model,
});

// Don't forget to close when done
adapter.close();
```

## Configuration options

```typescript
import {
  Spreadsheet,
  info,
  rowCount,
  tables,
} from '@deepagents/text2sql/spreadsheet';

new Spreadsheet({
  // Required: Path to Excel or CSV/TSV file
  file: './data.xlsx',

  // Required: Grounding functions for schema introspection
  grounding: [tables(), info(), rowCount()],

  // Optional: Persist SQLite database to file (default: in-memory)
  database: './cache.db',
});
```

## Supported file formats

| Format | Extension       | Table naming                                         |
| ------ | --------------- | ---------------------------------------------------- |
| Excel  | `.xlsx`, `.xls` | Each sheet becomes a table (sheet name → table name) |
| CSV    | `.csv`          | Filename becomes table name                          |
| TSV    | `.tsv`          | Filename becomes table name                          |

## Table and column naming

The adapter automatically sanitizes identifiers for SQL compatibility:

| Original                                    | Sanitized                                       | Rule                                                            |
| ------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------------- |
| `My Sheet!`                                 | `my_sheet`                                      | Special chars → underscore, lowercase                           |
| `123Data`                                   | `_123data`                                      | Prefix underscore if starts with number                         |
| `Customer ID`                               | `customer_id`                                   | Spaces → underscores                                            |
| `aaaa...` (100 chars)                       | `aaaa...` (64 chars)                            | Truncated to 64 characters                                      |
| `Customer ID`, `Customer-ID`, `customer_id` | `customer_id`, `customer_id_2`, `customer_id_3` | Names that sanitize to the same identifier get numeric suffixes |

## Type inference

The adapter infers each column's SQLite type from its values:

| Data pattern               | SQLite type | Example values         |
| -------------------------- | ----------- | ---------------------- |
| All integers               | `INTEGER`   | `1`, `42`, `100`       |
| Numbers including decimals | `REAL`      | `3.14`, `99.99`        |
| Dates                      | `TEXT`      | Stored as `YYYY-MM-DD` |
| Mixed/text                 | `TEXT`      | `"hello"`, `"123"`     |

Missing values and empty strings in an existing column become SQL `NULL`.
CSV columns with no populated cells are omitted from the table.

## Multi-sheet Excel files

Each sheet in an Excel file becomes a separate table that you can query and join:

```typescript
import { Spreadsheet, tables } from '@deepagents/text2sql/spreadsheet';

// sales.xlsx has sheets: "Customers", "Orders", "Products"
const adapter = new Spreadsheet({
  file: './sales.xlsx',
  grounding: [tables()],
});

// Query individual tables
const customers = await adapter.execute('SELECT * FROM customers');

// Join across sheets
const results = await adapter.execute(`
  SELECT c.name, o.amount
  FROM customers c
  JOIN orders o ON c.id = o.customer_id
`);

adapter.close();
```

## Available grounding functions

The `Spreadsheet` adapter reuses SQLite grounding functions. Import them from `@deepagents/text2sql/spreadsheet`:

| Function         | Description                                            |
| ---------------- | ------------------------------------------------------ |
| `tables()`       | Lists all tables (sheets) with their columns and types |
| `info()`         | Reports SQLite dialect and version info                |
| `rowCount()`     | Counts rows per table with size classification         |
| `columnStats()`  | Collects min, max, null fraction for columns           |
| `columnValues()` | Samples distinct values from columns                   |

See [Grounding](/docs/text2sql/grounding) for detailed configuration options.

## Persisting the database

Set `database` to save the imported tables in a SQLite file:

```typescript
const adapter = new Spreadsheet({
  file: './large-dataset.xlsx',
  database: './cache.db', // SQLite file is created here
  grounding: [tables()],
});

adapter.close();
```

Open the saved SQLite file directly to query it in a later session. Import
into a fresh database file: each `Spreadsheet` constructor creates the tables
again and fails if a table with the same name already exists.

## Handling special data

### Unicode and international characters

```typescript
// Full Unicode support including CJK, accents, and emoji
const adapter = new Spreadsheet({
  file: './international-data.xlsx',
  grounding: [tables()],
});

const results = await adapter.execute(
  "SELECT * FROM data WHERE text LIKE '%日本%'",
);
```

### Dates

Excel dates are automatically converted to `YYYY-MM-DD` format:

```typescript
// Query date ranges
const events = await adapter.execute(`
  SELECT * FROM events
  WHERE date >= '2024-01-01' AND date < '2025-01-01'
`);
```

### NULL values

Empty cells and missing values in existing columns become SQL `NULL`:

```typescript
// Find rows with missing emails
const incomplete = await adapter.execute(`
  SELECT * FROM customers WHERE email IS NULL
`);
```

## Error handling

| Error                           | Cause                                                | Solution                                                           |
| ------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------ |
| `Failed to read spreadsheet`    | File not found or corrupted                          | Check file path and format                                         |
| `No valid sheets found`         | All sheets are empty or have no usable columns       | Include headers and at least one data row                          |
| `table "<name>" already exists` | The database already contains a table being imported | Import into a fresh database file or query the saved file directly |

## Full example

```typescript
import { Text2Sql, toSql } from '@deepagents/text2sql';
import {
  Spreadsheet,
  columnStats,
  info,
  rowCount,
  tables,
} from '@deepagents/text2sql/spreadsheet';

// Load an Excel file with customer and order data
const adapter = new Spreadsheet({
  file: './ecommerce.xlsx',
  grounding: [tables(), info(), rowCount(), columnStats()],
});

const text2sql = new Text2Sql({
  adapters: { main: adapter },
});

// Introspect schema
const schema = await adapter.introspect();
console.log('Schema:', schema);

const fragments = await text2sql.index({ names: ['main'] });
const { sql: topCustomers } = await toSql({
  input: 'Who are the top 10 customers by total order amount?',
  adapter,
  fragments,
  model,
});
console.log('SQL:', topCustomers);

const results = await adapter.execute(topCustomers);
console.log('Results:', results);

// Always close when done
adapter.close();
```

## Size hints

Tables are classified by row count (inherited from SQLite adapter):

| Size hint | Row count       |
| --------- | --------------- |
| tiny      | < 100           |
| small     | 100 - 999       |
| medium    | 1,000 - 9,999   |
| large     | 10,000 - 99,999 |
| huge      | >= 100,000      |
