---
title: Build an agent (SQLite store)
description: Step-by-step recipe for a streaming Text2SQL agent with a SQLite-backed context store
---

Build a streaming Text2SQL chat agent with conversation history stored in
SQLite. The query adapter connects to your data source; `SqliteContextStore`
keeps the conversation in a separate database.

## 1. Install

```bash
npm install @deepagents/context @deepagents/text2sql @ai-sdk/groq
```

Add the driver or connection helper for the database you want to query:

```bash
npm install pg          # PostgreSQL
npm install mssql       # SQL Server
npm install mysql2      # MySQL / MariaDB
npm install @duckdb/node-api         # DuckDB
npm install @google-cloud/bigquery   # BigQuery
npm install @clickhouse/client       # ClickHouse, or use your preferred client
npm install @zukhruf/sqlite-open      # Connection helper for node:sqlite
```

## 2. Open the SQLite context store

The context store saves conversation messages and usage in a single `.db`
file. When given a path, `SqliteContextStore` opens it through
`@zukhruf/sqlite-open`, enabling write-ahead logging (WAL) and a five-second
busy timeout, then applies its schema. Non-message fragments such as indexed
schema and instructions must be added to each new `ContextEngine` instance.

```typescript
import { SqliteContextStore } from '@deepagents/context';

const store = new SqliteContextStore('./agent.db');
```

## 3. Create the SQL adapter

The adapter is the database the agent will query. Pick one. The adapter map
key (`main` here) is the selector the CLI uses inside the sandbox.

<Tabs groupId="database" items={['SQLite', 'PostgreSQL', 'DuckDB', 'SQL Server', 'MySQL/MariaDB', 'BigQuery', 'ClickHouse']}>

<Tab value="SQLite">

```typescript
import { open } from '@zukhruf/sqlite-open';

import { Sqlite } from '@deepagents/text2sql/sqlite';
import * as sqlite from '@deepagents/text2sql/sqlite';

const db = open('./your-database.db', { readOnly: true });
const adapter = new Sqlite({
  execute: (sql) => db.prepare(sql).all(),
  grounding: [sqlite.tables(), sqlite.info()],
});
```

<Tab value="PostgreSQL">

```typescript
import pg from 'pg';

import { Postgres } from '@deepagents/text2sql/postgres';
import * as postgres from '@deepagents/text2sql/postgres';

const pool = new pg.Pool({ connectionString: process.env.DATABASE_URL });
const adapter = new Postgres({
  execute: async (sql) => (await pool.query(sql)).rows,
  grounding: [postgres.tables(), postgres.info()],
});
```

<Tab value="DuckDB">

```typescript
import { DuckDBInstance } from '@duckdb/node-api';

import { DuckDB } from '@deepagents/text2sql/duckdb';
import * as duckdb from '@deepagents/text2sql/duckdb';

const instance = await DuckDBInstance.create('./analytics.duckdb', {
  access_mode: 'READ_ONLY',
});
const connection = await instance.connect();
const adapter = new DuckDB({
  execute: async (sql) => {
    const reader = await connection.runAndReadAll(sql);
    return reader.getRowObjectsJson();
  },
  grounding: [duckdb.tables(), duckdb.info()],
});
```

import { Mysql } from '@deepagents/text2sql/mysql';

const pool = mysql.createPool({

  user: process.env.DB_USER,

  database: process.env.DB_NAME,

const adapter = new Mysql({
  execute: async (sql) => {
    const [rows] = await pool.query(sql);

  grounding: [mysqlGrounding.tables(), mysqlGrounding.info()],

<Tab value="BigQuery">

```typescript
import { BigQuery as BigQueryClient } from '@google-cloud/bigquery';

import { BigQuery } from '@deepagents/text2sql/bigquery';
import * as bigquery from '@deepagents/text2sql/bigquery';

const projectId = process.env.BQ_PROJECT_ID!;
const client = new BigQueryClient({ projectId });
const adapter = new BigQuery({
  projectId,
  datasets: ['analytics'],
  execute: async (sql) => {
    const [job] = await client.createQueryJob({ query: sql });
    const [rows] = await job.getQueryResults();
    return rows;
  },
  validate: async (sql) => {
    await client.createQueryJob({
      query: sql,
      dryRun: true,
      useQueryCache: false,
    });
  },
  grounding: [bigquery.tables(), bigquery.info()],
});
```

import { createClient } from '@clickhouse/client';

import { ClickHouse } from '@deepagents/text2sql/clickhouse';

const client = createClient({
  url: process.env.CLICKHOUSE_URL,
  username: process.env.CLICKHOUSE_USER,
  password: process.env.CLICKHOUSE_PASSWORD,

const query = async (sql: string) => {
  const result = await client.query({ query: sql, format: 'JSON' });
  return result.json();

const adapter = new ClickHouse({
  defaultDatabase: 'analytics',
  execute: query,
  validate: async () => undefined,
  grounding: [clickhouse.tables(), clickhouse.info()],
});

## 4. Create the model

```typescript
import { groq } from '@ai-sdk/groq';

const model = groq('openai/gpt-oss-20b');
```

## 5. Build the ContextEngine and index the schema

`ContextEngine` reads and writes the SQLite store using `chatId` + `userId` as
the thread key. `AdapterIndexer` walks the adapter's grounding and returns
schema fragments; without an injected `cache` (e.g. `FileIndexCache`) it
introspects fresh each call. See the package README's "Schema index caching"
section.

```typescript
import { ContextEngine } from '@deepagents/context';
import { AdapterIndexer, instructions } from '@deepagents/text2sql';

const context = new ContextEngine({
  store,
  chatId: 'chat-123',
  userId: 'user-456',
});

const indexer = new AdapterIndexer({
  adapters: { main: adapter },
});

context.set(...instructions(), ...(await indexer.index()));
```

## 6. Author the adapter map for the sandbox

The agent runs the `sql` CLI inside a container. The CLI loads adapters from
the path in `TEXT2SQL_ADAPTERS`. Write a module that default-exports your
adapter map and mount it into the sandbox.

```typescript
// /workspace/text2sql-adapters.ts (inside the sandbox)
import { adapter } from './build-adapter.ts';

export default { main: adapter };
```

## 7. Provision the sandbox

```typescript
import { createBashTool, createDockerSandbox, npm } from '@deepagents/context';
import { createSqlCommandHooks } from '@deepagents/text2sql';

const backend = await createDockerSandbox({
  installers: [npm('@deepagents/text2sql', { ensureRuntime: true })],
  volumes: [
    {
      type: 'bind',
      hostPath: process.cwd(),
      containerPath: '/workspace',
      readOnly: true,
    },
  ],
  env: {
    TEXT2SQL_ADAPTERS: '/workspace/text2sql-adapters.ts',
    TEXT2SQL_OUT_DIR: '/tmp/text2sql',
  },
});
const sandbox = await createBashTool({
  sandbox: backend,
  ...createSqlCommandHooks({ adapters: { main: adapter } }),
});
```

If you are not mounting your project into `/workspace`, upload or write
`/workspace/text2sql-adapters.ts` before the first `chat()` call.

`TEXT2SQL_OUT_DIR` keeps generated SQL artifacts in writable `/tmp` while the
project mount stays read-only. Bind-mount paths refer to the Docker host;
with a remote daemon, the project must exist on that host.

## 8. Wire the agent

```typescript
import { agent, errorRecoveryGuardrail } from '@deepagents/context';

const ai = agent({
  name: 'sql-assistant',
  sandbox,
  model,
  context,
  guardrails: [errorRecoveryGuardrail],
  maxGuardrailRetries: 3,
});
```

## 9. Run a turn

`context.continue(...)` appends the new user message and reserves an empty
assistant slot. `chat(ai)` streams the response and saves completed assistant
message segments and usage to the context store. To persist individual stream
chunks for replay or reconnection, add
[stream persistence](/docs/context/stream-persistence).

```typescript
import { chat, user } from '@deepagents/context';

await context.continue(user('What are the most popular genres?'));
const stream = await chat(ai);

for await (const chunk of stream) {
  // render chunk
}
```

## 10. Reuse the thread

Open a new process pointing the same `chatId`/`userId` at the same
`./agent.db`. The history loads automatically; just call `continue` + `chat`
again.

```typescript
const store = new SqliteContextStore('./agent.db');
const context = new ContextEngine({
  store,
  chatId: 'chat-123',
  userId: 'user-456',
});
context.set(...instructions(), ...(await indexer.index()));
// ai = agent({ ... }) as before

await context.continue(user('Now break it down by country.'));
for await (const chunk of await chat(ai)) {
  // render chunk
}
```
